# Phrases of the voice commands, in English (file VOICE_EN.TXT of the configuration drive).
# Each [s_...] section is named after the list of the code it fills; one pattern per line.
# Patterns: [optional part], (choice|other choice), nested if needed: [i have ]another question
# Write in lowercase, accents kept, apostrophes and hyphens as spaces ("let s"), no punctuation.
# English is also the fallback: a section missing in another language's file is taken from here.
# An empty section disables the command. Lines starting with # are comments. Emptied file: restored.
